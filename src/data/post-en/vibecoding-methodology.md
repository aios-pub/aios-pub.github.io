Programming is undergoing a revolution. The rise of AI has changed the way we interact with code, and VibeCoding has emerged - a brand new programming methodology that redefines the development experience with intuition and creativity.

## What is VibeCoding?

VibeCoding is an AI-era programming methodology with a core philosophy of:

> **Guide with intuition, let AI implement, create as the foundation.**

Traditional programming requires precise syntax and detailed instructions, while VibeCoding lets you describe intent in natural language and let AI understand and implement. You no longer need to focus on every detail, but on creativity and goals.

## Core Principles of VibeCoding

### 1. Intuition First

Trust your intuition and express your ideas in the most natural way:

```
Traditional: Write detailed loops and conditional judgments
VibeCoding: Describe the result you want, let AI generate code
```

### 2. Iterative Dialogue

Continuously optimize results through dialogue:

1. Describe your initial idea
2. Review AI's output
3. Provide improvement suggestions
4. Repeat until satisfied

### 3. Context Awareness

AI understands your project context and generates code that matches the overall style:

- Code style consistency
- Architecture pattern matching
- Correct dependency relationships

### 4. Creativity Unleashed

Liberated from tedious syntax details, focus on creation:

- Rapid prototype validation
- Explore multiple solutions
- Realize creative ideas

## VibeCoding Practice Guide

### Basic Techniques

**Clearly Describe Intent**

```
❌ "Write a function"
✅ "Write a function that takes a user-input email address, validates if the format is correct, and returns a boolean value"
```

**Provide Context**

```
❌ "Add a button"
✅ "Add a save button on the user settings page, using the project's primary color, show a save success message after clicking"
```

**Step by Step**

```
1. First describe the overall structure
2. Then refine each part
3. Finally handle details and styling
```

### Advanced Techniques

**Role Setting**

```
"You are a senior front-end engineer, proficient in React and TypeScript..."
```

**Example-Driven**

```
"Generate similar content following this format:..."
```

**Constraint Conditions**

```
"Code needs to be compatible with IE11, use ES5 syntax..."
```
